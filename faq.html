Frequently Asked Questions

Click a question to see the answer. Still stuck? See the full user guide.

Is my data uploaded anywhere?

No. The backup zip is read entirely inside your browser tab. It's never sent to QuickFile, to Anthropic, or to any other server — closing the tab clears everything.

Is this an official QuickFile product?

No — this is an independent companion tool built to complement QuickFile, not an official QuickFile feature. Your account and data remain entirely within QuickFile; this tool only reads a backup you choose to export from it.

Why does a bank account show no nominal code or name?

The tool only labels an account when it can match it to a nominal code with a high degree of confidence, based on your nominal ledger. If it can't be confident, it still shows the account and its transactions — it just leaves the code and name blank rather than guessing.

Why don't the figures here exactly match a report inside QuickFile?

This tool calculates everything itself, directly from the backup's line-level data, rather than using QuickFile's own report engine — so definitions can differ slightly (for example, net versus gross, or which date a line is counted against). Treat this tool as a complementary view for questions QuickFile doesn't answer directly, and QuickFile itself as the source of truth for your accounts.

Does this replace QuickFile?

No. You still raise invoices, record payments, reconcile your bank feed and file returns in QuickFile as normal. This tool only reads a backup of that data to answer extra reporting questions.

What if I close the browser tab or refresh the page?

Your loaded data is cleared and the tool resets to the example figures — nothing is saved between visits. Just choose your backup zip again to pick up where you left off.

Can I download the results as a file?

Not directly — click Copy CSV to copy the report currently on screen (with your filters and sort order applied) to your clipboard, then paste it into Excel or Google Sheets.

Do I need a QuickFile account to use this?

You need a QuickFile backup zip, which means access to a QuickFile account to generate one. The tool itself doesn't ask you to sign in or create an account.

How do I get a backup from QuickFile?

In QuickFile, go to Account Settings → All Settings → Monthly Backups, enter an email address, and click Run Now. You'll receive an email with a link to download your backup — that's the zip file to choose in this tool.

Why don't I see my project or property tags?

Reports grouped by project — Sales by project, Profit by project, and similar — need project data to be included in the backup. When you create the backup in QuickFile, make sure the Include Projects box is ticked; it isn't ticked by default, and without it your tags won't come through.

A report looks wrong — what should I check first?

Make sure you've loaded your own backup rather than the example data (the file name near the top of the page confirms this), and check any date range, "12 months ending" or checkpoint-date filter — a figure that looks missing is often just outside the window currently selected.

Please also note that QuickFile backups are taken from a copy of your data which can be up to 24 hours old, so recently entered data may not be included yet — if something you just added is missing, try again with a fresh backup exported a little later.

What browsers or devices does this work on?

Any modern desktop browser — Chrome, Edge, Firefox or Safari. It also works on phones and tablets, though the report tables are easier to read on a larger screen.

How large a backup can this handle?

There's no hard limit — backups with many thousands of invoice lines work fine. A very large backup, or one covering many years of history, may just take a few extra seconds to load and process.

Will my report choice and filters be remembered next time?

No — since nothing is saved between visits, you'll need to choose your report and reload your backup zip each time you open the page.
